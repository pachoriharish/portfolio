## 🚀 Run it

Open `index.html` in any browser, or serve the folder:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```

## 🌍 Deploy on InfinityFree

1. Log in to your [InfinityFree](https://www.infinityfree.com/) client area and open your hosting account.
2. Open the **Online File Manager** (or connect with an FTP client using the FTP details shown in your account).
3. Go into the **`htdocs`** folder. This is your site's public root.
4. Delete any default placeholder page, then upload `index.html`, `photo.jpg` and `Harish_Pachori_Resume.pdf` directly inside `htdocs`. Upload `README.md` only if you want it there. It isn't needed for the site.
5. Visit your InfinityFree domain. New uploads can take a few minutes to appear.

> **Tip:** if you host more than one site on the account, upload this one to its own domain's `htdocs`, so it doesn't overwrite your other projects.

## 🛠️ Customise

| To change | Where |
|---|---|
| Typing phrases | `const ph=[...]` in the script at the bottom of `index.html` |
| Skills and descriptions | `const S={...}` in the same script |
| Colours | CSS variables at the top of the `<style>` block |
| Photo and resume | Replace `photo.jpg` and `Harish_Pachori_Resume.pdf` (keep the names) |
| Email and GitHub | Search `index.html` for `pachoriharish` |

> **Add a project:** copy a `<div class="proj">…</div>` block inside `#projects`, edit the text and links, and place it above the `<div class="soon">` placeholder.
